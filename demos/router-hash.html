Hash routing

The app path lives after the #, so the server only ever sees this one file. Deep links and refreshes work on any static host with no rewrite rules — which is why this documentation site uses it.

Things to try

  • Click the links and watch the real address bar above the page change.
  • Type into the shell input, then navigate — it keeps its value, because the shell is reconciled rather than rebuilt.
  • Press reload on a deep link like #/users/7. It comes straight back.
